# 真实公开来源边界

## 苏宁公开搜索页适配器

用途：对单个关键词的公开搜索首屏生成低频商品和页面展示价快照。

截至 2026-08-20 的检查结果：

- `https://search.suning.com/robots.txt` 未整体禁止公开关键词路径；
- 运行时重新检查规则，不访问其中禁止的 `/emall/`、`.do` 和含特定参数的路径；
- 不登录、不翻页、不并发，一次最多保留首屏 30 件商品；
- 只读取标题、展示价、评价数、店铺、卖点、商品链接和图片链接；
- 不访问用户、订单、购物车、会员或商家后台数据；
- 页面结构异常、验证、HTTP 错误或 robots 规则变化时停止。

页面初始 HTML 中价格占位符为空，因此项目使用本机 Edge 执行页面自身脚本，再读取公开展示价；不调用未公开价格接口。

## 什么值得买分类页实验

用途：对单个公开分类页生成一次低频消费者洞察快照，用于非商业作品集研究。

截至 2026-08-20 的检查结果：

- `https://www.smzdm.com/robots.txt` 没有整体禁止 `/fenlei/`；
- `https://search.smzdm.com/robots.txt` 明确 `Disallow: /`，因此本项目不采集搜索子域；
- 不访问登录页、账户页、评论用户资料、购买跳转或未公开接口；
- 不翻页、不并发，一次运行最多尝试读取当前分类页 30 条公开卡片；
- 出现验证码、安全验证、访问限制或页面结构异常时立即停止；
- 不自动解决验证码，不使用代理池，不伪造设备指纹；
- 输出仅保留内容标题、摘要、聚合互动数、日期和来源证据，不保存作者账号。

当前独立 Playwright 访问会收到 HTTP 202 探针页，因此该适配器会按规则停止，不计入自动化生产数据源。

`robots.txt` 不是法律授权，也不能代替网站条款。运行前会重新读取规则；项目若用于商业用途或扩大采集规模，必须先取得数据源许可并完成合规评估。

## 数据质量限制

- 页面内容是用户经验和优惠信息，不代表成交量或完整商品库；
- 文本中提取的价格可能是历史价、券后价或对比价；
- 互动数与发布时间是采集时页面展示值；
- 所有 AI 结论必须附带原文链接和采集时间，不能把推断包装成平台官方统计。
