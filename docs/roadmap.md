# 开发路线

## M1：可复现采集链路

- 自有动态商品站；
- 会话、签名、时间戳、nonce 与限流；
- 分页采集、重试、去重、校验和导出；
- Docker Compose 一键启动。

## M2：页面与协议演进

- 增加 v1/v2 页面结构；
- 增加字段弃用和 schema 版本；
- 添加契约测试与解析回归样本；
- 生成失败原因和字段完整率报告。

## M3：任务调度与存储

- Redis 队列；
- PostgreSQL 原始层、清洗层与分析层；
- 幂等任务、断点续跑和死信队列；
- Prometheus 指标和简单看板。

## M4：AI 市场调研

- 将清洗数据发送至 Dify 工作流；
- 生成价格带、竞品矩阵和异常商品报告；
- 每条结论保留商品 ID、来源和采集时间；
- 建立固定评测集，检测数据与回答质量。

## M5：真实公开来源适配器

只选择明确允许访问或获得授权的数据源。每个适配器附带：用途、访问边界、速率限制、停止条件、字段映射和维护记录。

- [x] 苏宁公开搜索商品与展示价快照；
- [x] 什么值得买访问边界与停止条件实验；
- [x] 自动价格带、店铺集中度、商品属性和证据报告；
- [ ] 第二个可自动运行的国内公开来源；
- [ ] 统一 `SourceAdapter` 接口和跨来源商品实体匹配；
- [ ] Dify 消费者痛点、价格带和渠道提及分析工作流。
